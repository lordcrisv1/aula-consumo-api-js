# Aula Prática: Consumo de APIs em JavaScript

Como Professor, Desenvolvi repositório para a aula teste do processo seletivo do SENAI-SP (Edital 104-2026).

## 🎯 Objetivo da Aula
Capacitar os alunos a compreenderem o funcionamento de requisições assíncronas no ecossistema JavaScript, aplicando validações de dados (Boas Práticas) e tratamento de exceções (Tratamento de Erros) na integração com Serviços Web.

## 🛠️ Tecnologias Utilizadas
* **HTML5:** Estrutura semântica da aplicação.
* **CSS3:** Estilização responsiva e padronização visual.
* **JavaScript (ES6+):** Lógica assíncrona com `Fetch API`, `async/await` e manipulação de DOM.
* **API Utilizada:** [ViaCEP](https://viacep.com.br/) (Serviço gratuito de localização de CEPs).

## 🚀 Conceitos Chave Abordados
1. **Assincronismo & Promises:** Como o JavaScript lida com requisições que dependem do tempo de resposta da rede.
2. **Sintaxe async/await:** Código assíncrono escrito de forma limpa e legível (síncrona).
3. **Tratamento de Erros (try...catch):** Garantia de resiliência da aplicação contra falhas de rede ou dados inexistentes.
4. **Boas Práticas:** Validação prévia de inputs no cliente para otimização de recursos.
